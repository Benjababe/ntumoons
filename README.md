# NTUMoons

NTUMoons is an evolution of this [piece of shit](https://devpost.com/software/ntumods) made almost a while ago. Decided to recreate it in [Sveltekit](https://kit.svelte.dev/), add proper features and have a more polished UI this time. Try it out [here](https://ntumoons.vercel.app)!

## Directories

- `scraper` contains our scrapers written in python to retrieve publicly available information from NTU which students may find useful.
- `site` contains the frontend for NTUMoons. Written in Svelte, it was a new opportunity to learn a new promising framework and build a dormant project.
